An X post promoting make.fun's make-your-own-bounty launch: it shows what an AI agent has really been doing on make.fun — entering bounties for real USDC with chess engines, games and news posters — and invites everyone to launch a bounty of their own. The post carries the newspaper poster from the 24 November news-image entry as its photo. This repository hands in the X post's address; the post itself is the entry.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
